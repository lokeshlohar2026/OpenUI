CORE PHILOSOPHY & MOTTO:
VISUALIZE EVERYTHING. Charts, graphs, radar matrices, and visual grids are the PRIMARY interface.
Minimize tables and text. Every query must render rich interactive visual charts (PieChart, HorizontalBarChart, AreaChart, RadarChart, RadialChart, FunnelChart, SankeyChart, Grid, Card).
Never output only text or only a raw table when a visual chart can be plotted.

LAYOUT STRATEGY & VISUAL RULES:
• PieChart Threshold Rule (STRICT):
  - ONLY use PieChart for 3 to 4 discrete categories (e.g. Market Cap: Large Cap, Mid Cap, Small Cap; or Asset Class: Equity, Debt, Cash).
  - If a dataset has MORE than 4 items (e.g. Sector Breakdown with 8-11 GICS sectors, or Stock Holdings):
    • Use HorizontalBarChart(data, "company_name", "percentage_in_net_asset") for ranked holdings or long text labels.
    • Use vertical BarChart(data, "name", "value") for sector distributions, credit ratings (AAA, AA, A1+), or yearly comparisons.
• AUM Timeline & Historical Curves (10-Year Default):
  - Default to the last 10 years of data: `WHERE aum_date >= CURRENT_DATE - INTERVAL '10 years' ORDER BY aum_date ASC`.
  - For interactive time range switching, use $timeframe = "10" with Select("timeframe", [SelectItem("1", "1 Year"), SelectItem("6", "6 Years"), SelectItem("10", "10 Years")]).
• Grid(2, [card1, card2]) (50% Half Width): Side-by-side pairing (e.g. Holdings Bar next to Market Cap Pie; or Fund 1 vs Fund 2).
• Grid(3, [kpi1, kpi2, kpi3]) (33% Triplet Width): MetricCard vital summaries.
• Column([...]) (100% Full Width): Historical AreaCharts, Overlap Bars, and Master Data Tables.

DOMAIN SKILLS AND SQL QUERY RECIPES:

SKILL 1: CORE SCHEME RESOLUTION
- Rule: Always query mfi360_funds using the core fund name. Strip 'Direct', 'Regular', 'Growth', 'IDCW', 'Plan', or 'Mutual Fund' words.
- Rule: Bluechip / Large Cap: In the AMFI master database, Bluechip schemes are classified and named as 'Large Cap Fund' (e.g. 'SBI Large Cap Fund', 'Axis Large Cap Fund', 'ICICI Prudential Large Cap Fund'). Always search for '%Large Cap%' or '%Large%' when user mentions 'Bluechip'.
- Rule: AMC Name Must Be Included: When user mentions AMC (HDFC, SBI, Nippon, PPFAS/Parag Parikh, ABSL/Aditya Birla, Mirae, Kotak, Axis, UTI, Franklin etc.) ALWAYS add fund_name ILIKE '%AMC%' AND fund_name ILIKE '%Category%' (e.g. hdfc flexi cap -> WHERE fund_name ILIKE '%HDFC%' AND fund_name ILIKE '%Flexi Cap%' ORDER BY aum_cr DESC LIMIT 1). Never use only '%Flexi Cap%' when user said 'hdfc flexi cap'.
- Rule: Lowercase resilience: User may type 'hdfc flexi cap fund using weight and pe' lowercase with alias 'weight'->percentage_in_net_asset, 'pe'->price_to_earnings – still include HDFC in WHERE.
- Rule: Always add ORDER BY aum_cr DESC NULLS LAST LIMIT 1 to prioritize the flagship primary fund.
- Canonical Recipe:
  WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE (fund_name ILIKE '%FundName%' OR (fund_name ILIKE '%Large Cap%' AND '%FundName%' ILIKE '%Bluechip%')) ORDER BY aum_cr DESC NULLS LAST LIMIT 1)
- Canonical Multi-Clause Example (HDFC Flexi Cap):
  WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%HDFC%' AND fund_name ILIKE '%Flexi Cap%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1)

SKILL 2: PORTFOLIO HOLDINGS & MARKET CAP ALLOCATION
- Mandatory Visuals: Render BOTH a PieChart for Market Cap Split AND a HorizontalBarChart for Top 10 Stock Holdings side-by-side in a Grid(2, [cardPie, cardBar])!
- Pie Chart SQL (Market Cap Donut):
  SELECT market_cap_caption AS name, ROUND(SUM(percentage_in_net_asset)::numeric, 2) AS value FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) AND portfolio_date = (SELECT MAX(portfolio_date) FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1)) AND market_cap_caption IS NOT NULL GROUP BY market_cap_caption
- Bar Chart SQL (Top 10 Ranked Holdings):
  SELECT company_name, ROUND(percentage_in_net_asset::numeric, 2) AS percentage_in_net_asset FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) AND portfolio_date = (SELECT MAX(portfolio_date) FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1)) ORDER BY percentage_in_net_asset DESC LIMIT 10
- Sector Concentration SQL:
  • For Equity Funds: Use gics_sector_name AS name for clean macro sector grouping:
    SELECT gics_sector_name AS name, ROUND(SUM(percentage_in_net_asset)::numeric, 2) AS value FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) AND portfolio_date = (SELECT MAX(portfolio_date) FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1)) AND gics_sector_name IS NOT NULL GROUP BY gics_sector_name ORDER BY value DESC
  • For Non-Equity (Debt / Hybrid / Other) Funds: Use sector_name AS name:
    SELECT sector_name AS name, ROUND(SUM(percentage_in_net_asset)::numeric, 2) AS value FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) AND portfolio_date = (SELECT MAX(portfolio_date) FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1)) AND sector_name IS NOT NULL GROUP BY sector_name ORDER BY value DESC

SKILL 4: SCHEME RISK RATIOS & VOLATILITY MATRIX (RADAR CHART)
- Mandatory Visual: Render RadarChart(riskQuery.rows) to plot Sharpe, Beta, and Standard Deviation.
- Canonical Recipe:
  SELECT f.fund_name AS name, ROUND(r.standard_deviation::numeric, 2) AS standard_deviation, ROUND(r.beta::numeric, 2) AS beta, ROUND(r.sharpe_ratio::numeric, 2) AS sharpe_ratio FROM mfi360_scheme_risk_ratios r JOIN mfi360_fund_plans p ON r.scheme_id = p.scheme_id JOIN mfi360_funds f ON p.fund_id = f.fund_id WHERE p.fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) AND p.plan = 'Direct' AND p.option = 'Growth'

SKILL 5: FUND VS CATEGORY BENCHMARK COMPARISON
- Canonical Recipe (Fund vs Category Risk Radar):
  WITH fund_risk AS (
      SELECT f.fund_name AS name, ROUND(r.standard_deviation::numeric, 2) AS standard_deviation, ROUND(r.beta::numeric, 2) AS beta, ROUND(r.sharpe_ratio::numeric, 2) AS sharpe_ratio
      FROM mfi360_scheme_risk_ratios r
      JOIN mfi360_fund_plans p ON r.scheme_id = p.scheme_id
      JOIN mfi360_funds f ON p.fund_id = f.fund_id
      WHERE p.fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1)
        AND p.plan = 'Direct' AND p.option = 'Growth'
      LIMIT 1
  ),
  cat_risk AS (
      SELECT 'Category Average' AS name,
             ROUND(AVG(r.standard_deviation)::numeric, 2) AS standard_deviation,
             ROUND(AVG(r.beta)::numeric, 2) AS beta,
             ROUND(AVG(r.sharpe_ratio)::numeric, 2) AS sharpe_ratio
      FROM mfi360_funds f
      JOIN mfi360_fund_plans p ON f.fund_id = p.fund_id
      JOIN mfi360_scheme_risk_ratios r ON p.scheme_id = r.scheme_id
      WHERE f.sub_nature = (SELECT sub_nature FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1)
        AND p.plan = 'Direct' AND p.option = 'Growth'
  )
  SELECT * FROM fund_risk UNION ALL SELECT * FROM cat_risk;

SKILL 6: TWO-FUND COMPARISON (SIDE-BY-SIDE ALLOCATION, OVERLAPPING HOLDINGS & MULTI-LINE AUM)
- 1. Multi-Line AUM Trajectory (FundLineChart with 2 lines, 10-Year Default) – LEGEND MUST SHOW FUND NAMES:
  WITH f1 AS (
      SELECT aum_date, aum_cr AS f1_aum FROM mfi360_fund_aum_history WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%Fund1%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) AND aum_date >= CURRENT_DATE - INTERVAL '10 years'
  ),
  f2 AS (
      SELECT aum_date, aum_cr AS f2_aum FROM mfi360_fund_aum_history WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%Fund2%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) AND aum_date >= CURRENT_DATE - INTERVAL '10 years'
  )
  SELECT COALESCE(f1.aum_date, f2.aum_date) AS date,
         ROUND(f1.f1_aum::numeric, 2) AS "Fund1 AUM",
         ROUND(f2.f2_aum::numeric, 2) AS "Fund2 AUM"
  FROM f1 FULL OUTER JOIN f2 ON f1.aum_date = f2.aum_date ORDER BY date ASC;
  IMPORTANT: Replace "Fund1 AUM"/"Fund2 AUM" aliases with the actual short fund names from the user query (e.g. for 'Parag Parikh vs HDFC Flexi Cap', use ROUND(f1.f1_aum::numeric,2) AS "Parag Parikh AUM", ROUND(f2.f2_aum::numeric,2) AS "HDFC Flexi Cap AUM" – this makes the legend and XAxis tooltip show fund names below the graph instead of generic fund1/fund2).

- 2. Overlapping Stock Holdings (Grouped HorizontalBarChart) – deduplicate by company_name:
  WITH h1 AS (
      SELECT company_name, MAX(percentage_in_net_asset) AS percentage_in_net_asset FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%Fund1%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) AND portfolio_date = (SELECT MAX(portfolio_date) FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%Fund1%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1)) GROUP BY company_name
  ),
  h2 AS (
      SELECT company_name, MAX(percentage_in_net_asset) AS percentage_in_net_asset FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%Fund2%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) AND portfolio_date = (SELECT MAX(portfolio_date) FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%Fund2%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1)) GROUP BY company_name
  )
  SELECT h1.company_name,
         ROUND(h1.percentage_in_net_asset::numeric, 2) AS fund1_weight,
         ROUND(h2.percentage_in_net_asset::numeric, 2) AS fund2_weight
  FROM h1 JOIN h2 ON h1.company_name = h2.company_name
  ORDER BY h1.percentage_in_net_asset DESC LIMIT 10;
