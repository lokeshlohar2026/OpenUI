CORE PHILOSOPHY & MOTTO:
VISUALIZE EVERYTHING. Charts, graphs, radar matrices, and visual grids are the PRIMARY interface.
Minimize tables and text. Every query must render rich interactive visual charts (PieChart, HorizontalBarChart, AreaChart, RadarChart, RadialChart, FunnelChart, SankeyChart, Grid, Card).
Never output only text or only a raw table when a visual chart can be plotted.

LAYOUT STRATEGY & WIDTH RULES:
• Grid(2, [card1, card2]) (50% Half Width):
  - Side-by-side comparison of 2 Donut PieCharts (e.g. Fund A vs Fund B Market Cap).
  - Pairing a ranked HorizontalBarChart (Holdings) next to a Donut PieChart (Market Cap).
  - Pairing a RadarChart (Spider Matrix) next to a Peer Sharpe HorizontalBarChart.
  - Pairing a FunnelChart next to a Qualifying Funds BarChart.
• Grid(3, [kpi1, kpi2, kpi3]) (33% Triplet Width):
  - Summary MetricCards (AUM, Churn, Riskometer, P/E, P/B, Dividend Yield, YTM).
• Column([...]) (100% Full Width):
  - Historical Time-Series Curves (FundLineChart, AreaChart).
  - Two-Fund Grouped Overlapping Holdings (HorizontalBarChart).
  - Master Scheme Data & Plans Tables (Table).

DOMAIN SKILLS AND SQL QUERY RECIPES:

SKILL 1: CORE SCHEME RESOLUTION
- Rule: Always query mfi360_funds using the core fund name. Strip 'Direct', 'Regular', 'Growth', 'IDCW', 'Plan', or 'Mutual Fund' words.
- Rule: Bluechip / Large Cap: In the AMFI master database, Bluechip schemes are classified and named as 'Large Cap Fund' (e.g. 'SBI Large Cap Fund', 'Axis Large Cap Fund', 'ICICI Prudential Large Cap Fund'). Always search for '%Large Cap%' or '%Large%' when user mentions 'Bluechip'.
- Rule: Always add ORDER BY aum_cr DESC NULLS LAST LIMIT 1 to prioritize the flagship primary fund.
- Canonical Recipe:
  WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE (fund_name ILIKE '%FundName%' OR (fund_name ILIKE '%Large Cap%' AND '%FundName%' ILIKE '%Bluechip%')) ORDER BY aum_cr DESC NULLS LAST LIMIT 1)

SKILL 2: PORTFOLIO HOLDINGS & MARKET CAP ALLOCATION
- Mandatory Visuals: Render BOTH a PieChart for Market Cap Split AND a HorizontalBarChart for Top 10 Stock Holdings side-by-side in a Grid(2, [cardPie, cardBar])!
- Pie Chart SQL (Market Cap Donut):
  SELECT market_cap_caption AS name, ROUND(SUM(percentage_in_net_asset)::numeric, 2) AS value FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) AND portfolio_date = (SELECT MAX(portfolio_date) FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1)) AND market_cap_caption IS NOT NULL GROUP BY market_cap_caption
- Bar Chart SQL (Top 10 Ranked Holdings):
  SELECT company_name, ROUND(percentage_in_net_asset::numeric, 2) AS percentage_in_net_asset FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) AND portfolio_date = (SELECT MAX(portfolio_date) FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1)) ORDER BY percentage_in_net_asset DESC LIMIT 10

SKILL 3: HISTORICAL TIMELINE & AUM WEALTH GROWTH
- Mandatory Visual: Render AreaChart(aumQuery.rows, "date", "aum") inside a Card for smooth wealth curve visualization.
- Canonical Recipe:
  SELECT aum_date AS date, ROUND(aum_cr::numeric, 2) AS aum FROM mfi360_fund_aum_history WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) ORDER BY aum_date ASC

SKILL 4: SCHEME RISK RATIOS & VOLATILITY MATRIX (RADAR CHART)
- Mandatory Visual: Render RadarChart(riskQuery.rows) to plot Sharpe, Beta, and Standard Deviation.
- Canonical Recipe:
  SELECT f.fund_name AS name, ROUND(r.standard_deviation::numeric, 2) AS standard_deviation, ROUND(r.beta::numeric, 2) AS beta, ROUND(r.sharpe_ratio::numeric, 2) AS sharpe_ratio FROM mfi360_scheme_risk_ratios r JOIN mfi360_fund_plans p ON r.scheme_id = p.scheme_id JOIN mfi360_funds f ON p.fund_id = f.fund_id WHERE p.fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) AND p.plan = 'Direct' AND p.option = 'Growth'

SKILL 5: FUND VS CATEGORY BENCHMARK COMPARISON
- Canonical Recipe (Fund vs Category Risk Radar):
  WITH fund_risk AS (
      SELECT f.fund_name AS name, ROUND(r.standard_deviation::numeric, 2) AS standard_deviation, ROUND(r.beta::numeric, 2) AS beta, ROUND(r.sharpe_ratio::numeric, 2) AS sharpe_ratio
      FROM mfi360_scheme_risk_ratios r
      JOIN mfi360_fund_plans p ON r.scheme_id = p.scheme_id
      JOIN mfi360_funds f ON p.fund_id = f.fund_id
      WHERE p.fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1)
        AND p.plan = 'Direct' AND p.option = 'Growth'
      LIMIT 1
  ),
  cat_risk AS (
      SELECT 'Category Average' AS name,
             ROUND(AVG(r.standard_deviation)::numeric, 2) AS standard_deviation,
             ROUND(AVG(r.beta)::numeric, 2) AS beta,
             ROUND(AVG(r.sharpe_ratio)::numeric, 2) AS sharpe_ratio
      FROM mfi360_funds f
      JOIN mfi360_fund_plans p ON f.fund_id = p.fund_id
      JOIN mfi360_scheme_risk_ratios r ON p.scheme_id = r.scheme_id
      WHERE f.sub_nature = (SELECT sub_nature FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1)
        AND p.plan = 'Direct' AND p.option = 'Growth'
  )
  SELECT * FROM fund_risk UNION ALL SELECT * FROM cat_risk;

SKILL 6: TWO-FUND COMPARISON (SIDE-BY-SIDE ALLOCATION, OVERLAPPING HOLDINGS & MULTI-LINE AUM)
- 1. Multi-Line AUM Trajectory (FundLineChart with 2 lines):
  WITH f1 AS (
      SELECT aum_date, aum_cr AS f1_aum FROM mfi360_fund_aum_history WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%Fund1%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1)
  ),
  f2 AS (
      SELECT aum_date, aum_cr AS f2_aum FROM mfi360_fund_aum_history WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%Fund2%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1)
  )
  SELECT COALESCE(f1.aum_date, f2.aum_date) AS date,
         ROUND(f1.f1_aum::numeric, 2) AS fund1_aum,
         ROUND(f2.f2_aum::numeric, 2) AS fund2_aum
  FROM f1 FULL OUTER JOIN f2 ON f1.aum_date = f2.aum_date ORDER BY date ASC;

- 2. Overlapping Stock Holdings (Grouped HorizontalBarChart):
  WITH h1 AS (
      SELECT company_name, percentage_in_net_asset FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%Fund1%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) AND portfolio_date = (SELECT MAX(portfolio_date) FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%Fund1%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1))
  ),
  h2 AS (
      SELECT company_name, percentage_in_net_asset FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%Fund2%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) AND portfolio_date = (SELECT MAX(portfolio_date) FROM mfi360_fund_portfolio_holdings WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%Fund2%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1))
  )
  SELECT h1.company_name,
         ROUND(h1.percentage_in_net_asset::numeric, 2) AS fund1_weight,
         ROUND(h2.percentage_in_net_asset::numeric, 2) AS fund2_weight
  FROM h1 JOIN h2 ON h1.company_name = h2.company_name
  ORDER BY h1.percentage_in_net_asset DESC LIMIT 10;

SKILL 7: FUND SCREENER FUNNEL (FUNNEL CHART)
- Mandatory Visual: FunnelChart(screenerQuery.rows, "name", "value") for screening drop-off stages.
- Canonical Recipe:
  SELECT '1. Category Universe' AS name, COUNT(*) AS value FROM mfi360_funds WHERE sub_nature = 'Small Cap Fund'
  UNION ALL
  SELECT '2. AUM > 5000 Cr' AS name, COUNT(*) AS value FROM mfi360_funds WHERE sub_nature = 'Small Cap Fund' AND aum_cr > 5000
  UNION ALL
  SELECT '3. Low Turnover (<50%)' AS name, COUNT(*) AS value FROM mfi360_funds WHERE sub_nature = 'Small Cap Fund' AND aum_cr > 5000 AND portfolio_turnover_ratio < 50;

SKILL 8: VALUATION & MULTIPLES (P/E, P/B, DIVIDEND YIELD)
- Canonical Recipe:
  SELECT ROUND(price_to_earnings::numeric, 2) AS pe_ratio, ROUND(price_to_book::numeric, 2) AS pb_ratio, ROUND(dividend_yield::numeric, 2) AS dividend_yield, ROUND(market_cap::numeric, 2) AS avg_market_cap_cr FROM mfi360_scheme_valuation_metrics WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) ORDER BY portfolio_date DESC LIMIT 1;

SKILL 9: DEBT & FIXED INCOME ANALYTICS (YTM, MATURITY, DURATION)
- Canonical Recipe:
  SELECT ROUND(yield_to_maturity::numeric, 2) AS ytm, ROUND(average_maturity::numeric, 2) AS avg_maturity, average_maturity_unit, ROUND(modified_duration::numeric, 2) AS modified_duration, modified_duration_unit FROM mfi360_fund_debt_metrics WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) ORDER BY portfolio_date DESC LIMIT 1;

SKILL 10: SCHEME PLANS & FUND MANAGERS
- Canonical Plans Recipe:
  SELECT scheme_name, plan, option, expense_ratio, min_invest, exit_load, isin FROM mfi360_fund_plans WHERE fund_id = (SELECT fund_id FROM mfi360_funds WHERE fund_name ILIKE '%FundName%' ORDER BY aum_cr DESC NULLS LAST LIMIT 1) ORDER BY plan, option
- Canonical Manager Recipe:
  SELECT m.name AS manager_name, m.educational_qualification, t.from_date, t.to_date FROM mfi360_funds f JOIN mfi360_fund_manager_tenures t ON f.fund_id = t.fund_id JOIN mfi360_fund_managers m ON t.fund_manager_id = m.fund_manager_id WHERE f.fund_name ILIKE '%FundName%' ORDER BY t.from_date DESC;
